시행일 / Effective: 2026-10-24

1. 접근하는 데이터

ddalkkak uploader는 사용자가 구글 로그인으로 허락한 범위 안에서 YouTube Data API를 통해 다음에 접근합니다: 사용자 본인 채널의 기본 정보(채널 이름·ID), 영상 업로드, 업로드한 영상의 정보 조회·수정·삭제.

2. 데이터 사용

이 데이터는 사용자 본인의 영상을 본인 채널에 올리고 관리하는 데에만 씁니다. 광고, 판매, 분석, 제3자 제공에 쓰지 않습니다.

3. 저장과 공유

로그인 토큰과 업로드 기록은 사용자 본인 PC에만 저장됩니다. 프로그램 개발자의 서버로 전송하지 않으며 어떤 제3자와도 판매·공유하지 않습니다.

예외: 사용자가 선택 기능인 AI 도우미(제목·설명 다듬기, 영상 검수)를 켜면, 그 작업에 필요한 영상 제목·설명 초안, 영상 장면 이미지, 공개 유튜브 검색 결과의 제목이 사용자가 직접 연결한 AI 서비스로 전송됩니다. 이 기능은 기본으로 꺼져 있습니다.

4. 삭제와 권한 철회

사용자는 언제든 Google 계정 → 타사 앱 액세스에서 권한을 철회할 수 있고, PC의 토큰 파일을 지우면 저장된 정보가 모두 삭제됩니다.

5. Google API 서비스 사용자 데이터 정책 준수

ddalkkak uploader가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 앱은 YouTube 서비스 약관과 Google 개인정보처리방침을 따르는 YouTube API 서비스를 사용합니다.

English summary

The app accesses only the signed-in user's own YouTube channel (channel info, video upload and management) via the YouTube Data API. Data is used solely to upload and manage the user's own videos, stored only on the user's own computer, never sent to the developer or sold/shared with third parties. Exception: if the user turns on the optional AI assistant, draft titles/descriptions, video frames and public YouTube search result titles are sent to the AI service the user connected. Access can be revoked at any time at Google Account → Third-party access. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
